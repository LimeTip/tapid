# Code of Conduct

Tapid follows the principles of the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

Everyone participating in the Tapid project, including in GitHub issues, discussions, pull requests, repositories, and official project spaces, is expected to be respectful, constructive, and professional.

Harassment, discrimination, threats, personal attacks, doxxing, retaliation, impersonation, and publication of private information are not acceptable.

To report conduct concerns, contact the Tapid maintainers privately through the official contact method listed on [tapid.dev](https://tapid.dev). Do not include unnecessary personal information or security-sensitive details in a conduct report.
